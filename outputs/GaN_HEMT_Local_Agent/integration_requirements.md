# 官方平台与大模型衔接清单

当前可运行范围：本地 ngspice / ASM-HEMT DC 仿真、规则规划、参数提取、验证、QA、导出与审计。真实官方 MCP 调用 0 次，国内 LLM 调用 0 次。`OfficialMCPBackend` 和 `DomesticLLMPlanner` 只是明确报错的占位入口，尚不是可用连接器。

## 需要取得的实际资料

1. 官方 MCP 服务器地址或启动方式、传输协议、允许的调用方式和鉴权约定。
2. 实际工具清单及输入/输出 schema、错误格式、限流与超时规则。尚未获知任何官方工具名，不能照搬本地日志中的名称。
3. 官方 ASM-HEMT 源码/版本、几何与端口映射、温度、自热开关、参数单位及允许范围。
4. 模型卡输入/输出格式、曲线数据格式、QA 判据和误差评分公式的正式说明。
5. 隐藏测试数据的访问边界、每器件调用次数的计数规则、实际运行时限与断线恢复约定。
6. 国内大模型服务的供应商、模型标识、端点、鉴权方式、工具调用能力、配额与费用限制。

鉴权数据应由环境变量或本机凭据提供；本项目不要求把密钥写进 JSON、模型卡、日志或分享包。这里仅说明所需配置，没有读取其他项目中的凭据。

## 后续适配步骤

- 按官方真实 schema 实现数据读取、参数设置、仿真、QA、模型导出等能力的映射。以上是能力描述，不是猜测的官方 API。
- 用同一参数卡、几何、温度和偏置网格比较本地与官方仿真。版本不同则先解决模型差异，不能直接比较拟合误差。
- 把 LLM 作为可替换规划器接入：输入仅包含允许的训练数据摘要、工具结果和预算；输出须经过参数界限、结构验证与权限检查。当前规则规划器仍可作为回退，但不能据此宣称完成了 LLM 调用要求。
- 保存真实请求/响应、工具名、服务返回标识、耗时与失败记录；敏感字段脱敏。正式 MCP 次数只从真实官方返回计数，本地仿真与故障注入单独计数。
- 按正式规则验收每器件的 MCP/LLM 调用、超时恢复、QA 与最终模型卡。现有本地验收不能替代参赛合规验收。

当前没有尝试访问未知端点，没有安装假设存在的官方服务，也没有发起付费模型调用。
