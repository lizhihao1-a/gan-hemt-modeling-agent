## 参数诊断

只使用作者原始 4824 个训练点，其中安全 gm 目标 3134 个，在上一版冻结参数处进行局部差分。23 参数 Jacobian 在相对奇异值阈值 1e−6 下数值秩为 **22/23**；条件数约 2.79e+07。这是归一化残差与参数范围下的局部数值诊断，不能解释为统计置信区间、全局可辨识性或唯一物理解。

接近公开范围边界的 10 个参数：RTH0, UB, VSAT, LAMBDA, UTE, DELTA, THESAT, VSATACCS, U0ACCD, MEXPACCS。变化步长 0.003 和 0.001 均在原范围内，边界处使用单边差分。单参数向内移动 2%、5%、10% 的代价变化见图；没有扩大范围，也没有在每次扰动后重拟合其他参数。

较强导数耦合（绝对余弦 >0.98）示例：NS0ACCS / U0ACCS (0.9981)。参数敏感性、步长一致性、所有耦合对和弱方向组合均保存在 diagnostics.json / parameter_sensitivity.csv / jacobian.npz。弱参数与耦合参数需靠独立温度、栅漏电或其他测量约束。

## Agent 闭环与最终模型

状态流：预检查 → 诊断 → 曲线组验证 → 规则规划 → 参数拟合 → 验证误差与本地 QA → 必要时细化 → 候选选择 → 全训练集重拟合 → QA 回退（如需要）→ 冻结 → 导出验证 → 报告。

先拟合 16 个核心参数；若验证 Id NRMSE 超过 2%、安全 gm NRMSE 超过 5% 或本地 QA 未通过，则在同一训练子集上细化全部 23 个参数。本次规则决策：**accept_core_16**，原因：predeclared validation and local QA thresholds satisfied。候选仅用预设 Vgs 组内部验证选择，随后仅用 4824 个训练点重拟合。所有初值来自公开范围中点及同一训练流程，未使用旧最佳参数作为新 Agent 的初值；诊断数据不用于改变交叉验证或候选计划。

最终本地 QA：True；接近边界的参数：RTH0, VSAT, LAMBDA, UTE, DELTA, THESAT。独立命令行读取导出模型卡，6030 点对齐通过，最大 Id 差异 1.42e-14 A。

原始留出集 1206 点电流 RMSE **0.926 mA**；按留出集观测极差归一化 **0.591%**。安全 gm 子集 66 点，RMSE **1.470 mS**。这个测试集在之前阶段已查看，本轮只在冻结后作回归检查，不作为新的盲测或模型选择证据。

当前日志包含 4926 次真实本地仿真尝试，其中失败 0 次。每次均记录参数、操作 ID、尝试号、耗时及结果。SciPy max_nfev 不包含全部数值 Jacobian 仿真，因此预算同时设有真实仿真次数上限和每项作业时间上限。单次仿真超时会终止隔离进程，最多重试一次。

## 恢复和验收

状态、输入/源码校验与阶段产物哈希持久化至 run_state.json。恢复时先验证校验值，跳过已完成阶段；已完成优化作业可以复用，未完成的优化作业按固定初值重新执行，未声称逐迭代无损续算。运行锁防止同一目录同时执行两个控制器。进程崩溃、超时、参数越界、产物篡改、恢复跳过及正式连接器禁用的验证结果见 results/acceptance.json（生成后可查看）。

本地流程验收与模型泛化精度分别报告；“流程完成”不表示所有参数已充分辨识或跨器件准确。
