# 下一步与建议分工

| 优先级 | 建议方向 | 完成标准 |
|---|---|---|
| P0 | 环境 / Nano | 最小 MOS 有 33 个有限电流值；参数扰动有效；关掉插桩仍通过；继而官方 GaN demo 5,160 点有效 |
| P1 | 官方建模接口 | 在工作副本上完成加载→仿真→参数变化→模型卡导出→保存重开→结果一致；拒绝 NaN 和全零假成功 |
| P1 | 数据与第二器件 | 按缺口表核实测量条件和样品编号，为 TLN2/GS65030 分别建立划分、偏置覆盖和质量审查记录 |
| P2 | Agent / 国内 LLM | 明确工具输入输出、有限数值检查、优化目标、预算、重试和检查点；记录真实 LLM/官方 MCP 调用 |

各方向的负责人由团队自行认领，不预设队友 GitHub 账号。环境尚未恢复时，数据核实、工具封装和离线测试可以独立推进。正式误差优化依赖 P0。

每个任务先开 Issue，写清输入、预期产物和验收标准。新结果写入独立运行目录，摘要通过 Pull Request 进入仓库，不覆盖现有报告或暗改数据划分。
